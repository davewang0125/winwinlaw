# WinWin Law Landing Page

A professional landing page inspired by LegalShield's design aesthetic and messaging approach.

## Features

- **Clean, Professional Design**: Modern layout with clear visual hierarchy
- **Responsive Layout**: Mobile-friendly design that adapts to all screen sizes
- **Interactive Elements**: Smooth animations, hover effects, and tab switching
- **Trust Signals**: Statistics, testimonials, and brand recognition
- **Clear CTAs**: Multiple conversion points throughout the page

## Design Approach

This landing page captures the professional, trustworthy aesthetic of leading legal service providers with:

- **Typography**: Lora serif for headings (professional, elegant) paired with Inter sans-serif for body text (clean, readable)
- **Color Scheme**: Professional blue palette (#1a5490) conveying trust and authority
- **Layout**: Traditional, accessible structure with clear sections and visual flow
- **Tone**: Reassuring and approachable messaging focused on accessibility and peace of mind

## Sections

1. **Hero Section**: Bold headline, key statistics, and primary CTA
2. **Trust Bar**: Social proof through brand recognition
3. **How We Help**: Tabbed content showing personal and business services
4. **How It Works**: 3-step process visualization
5. **Pricing**: Three-tier pricing with feature comparison
6. **Testimonials**: Customer reviews with star ratings
7. **CTA Section**: Final conversion opportunity
8. **Footer**: Comprehensive site navigation and legal links

## Technologies

- Pure HTML, CSS, and JavaScript (no framework dependencies)
- CSS Grid and Flexbox for responsive layouts
- Intersection Observer API for scroll animations
- CSS custom properties for easy theming

## Usage

Simply open `index.html` in a web browser. No build process or dependencies required.

## Customization

- Colors: Edit CSS variables in `:root` selector in `styles.css`
- Content: Update text directly in `index.html`
- Animations: Modify timing and effects in `script.js`

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge). Requires JavaScript enabled for interactive features.
